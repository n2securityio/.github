### Why N² Security

WordPress malware has changed. Modern infections hide where traditional scanners don't look:

- **ClickFix** — fake "verify you're human" pop-ups that trick visitors into running malicious commands
- **EtherHiding** — malicious code loaded from blockchain contracts, so it can't simply be taken down
- **Hidden reinfection** — scheduled tasks and backdoors tucked into the database that reinstall malware after cleanup

N² Security is designed to catch exactly these.

### Features

| | |
|---|---|
| 🔍 **AI Malware Analysis** | Detects obfuscated and injected code |
| 🚫 **C2 Beacon Blocker** | Cuts off malware's connection to its command servers |
| 🗄️ **DB Cron Cleaner** | Finds and removes hidden reinfection tasks in the database |
| 🛡️ **ClickFix & EtherHiding Defense** | Blocks fake verification pop-ups and blockchain-loaded payloads |
| 📋 **Activity Logger** | See who changed what, and when |
